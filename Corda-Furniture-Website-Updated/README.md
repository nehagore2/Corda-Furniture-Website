# Corda Furniture - Updated Website

## Included
- Responsive design for desktop, tablet, and mobile
- Image boxes that keep furniture images contained instead of cutting them
- Scroll reveal animations
- Responsive side navigation
- Catalog add-to-cart functionality using localStorage
- Cart summary and remove-item controls
- Contact form demo confirmation

## Run
Open `index.html` with VS Code Live Server.

## Important
This is a front-end assignment demo. Checkout and contact form do not connect to a real backend.
